# VIS-142 Visits need a status

## Story

Front-desk staff cancel and complete visits. No state exists.

## Acceptance

1. Status on each visit: SCHEDULED, COMPLETED, CANCELLED. New visits start SCHEDULED.
2. Allowed: SCHEDULED to COMPLETED, SCHEDULED to CANCELLED. Nothing out of COMPLETED or CANCELLED.
3. Transition rule in the domain model, not the controller.
4. Show status on the owner details page.
5. Update H2, MySQL, and Postgres schema and seed data.
6. Unit tests for every allowed and blocked change. All existing tests pass.
